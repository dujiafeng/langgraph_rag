# 高考志愿填报实用技巧

## 一、如何选择学校
1. **985 > 211 > 省重点**：学校层次在就业中有重要影响，在分数允许的情况下优先选择高层次的学校。
2. **城市因素**：北上广深等一线城市实习和就业机会更多，但竞争也更大。
3. **学科评估**：查看教育部学科评估结果（A+/A/A-），选择学校优势学科。
4. **校园开放日**：建议实地考察或参加线上招生宣讲会。

## 二、如何选择专业
1. **兴趣导向**：选感兴趣的专业才能长期坚持，不要盲目追求热门。
2. **就业前景**：了解目标专业的就业率、平均薪资、主要就业去向。
3. **专业壁垒**：临床医学、法学等有高专业壁垒的专业，跨行难但竞争压力小。
4. **学科交叉**：计算机+金融、数学+计算机等交叉背景更受就业市场欢迎。

## 三、填报策略
1. **冲稳保策略**：前20%志愿冲（高10-20分学校），中间60%稳（上下5分学校），后20%保（低10-30分学校）。
2. **平行志愿**：按"分数优先，遵循志愿"原则投档，高分考生优先。
3. **服从调剂**：建议勾选服从调剂，避免滑档到下一批次。
4. **提前批**：军校、公安、公费师范生等提前批次，录取后不影响后续批次。

## 四、时间节点
1. **6月7-8日**：全国统一高考
2. **6月23-26日**：各省陆续公布高考成绩
3. **6月下旬-7月初**：本科批次志愿填报
4. **7月中旬-8月初**：录取结果陆续公布

## 五、常见误区
1. **只看分数不看位次**：每年试卷难度不同，位次比分数更有参考价值。
2. **忽视选科要求**：新高考省份需注意专业选科要求，如临床医学需选化学+生物。
3. **热门专业扎堆**：热门专业录取线会虚高，可能性价比不如冷门强校。
4. **学校选择过于保守**：有能力的考生应大胆尝试更高层次学校。
